Methods guide

All policies use the same reward: +100 for an on-time arrival (within seven hours), +80 for late, or −50 for blocked, minus route cost. The historical profiles and the evaluation incidents are synthetic. The reported affected road records the main impact; notes can describe secondary delays or severity.

Q-learningEstimates a value for each route by averaging observed rewards through terminal Q-updates. It trains on balanced synthetic historical outcomes for every route, then selects the highest value from a frozen table. Useful for repeated decisions with measurable outcomes.CPU-only tabular training. Lookup is local.
